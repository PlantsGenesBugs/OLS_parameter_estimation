# Estimation of parameters in a multiple regression model, using ordinary least squares
In this repository I have analysed recent house price data in London to create a linear model that will predict house prices based on number of bedrooms, bathrooms, living rooms and surface area in square meter. Part of the modelling involves estimating the parameters (coefficients) associated with each feature (descriptive variable). This was done by applying the normal equation. I have compared my output with the linear modeling function in R. I have also assessed the effect of adding a categorical variable (post code) to the model. 

Code and descriptive text is available in R-markdown format, and a more user-friendly [github markdown version](https://github.com/PlantsGenesBugs/OLS_parameter_estimation/blob/main/manual_OLS_multi_regr.md).
